# company-site

スカイラインテクノロジーズのコーポレートサイトです。

## 概要

- 社会インフラ企業向けソフトウェア開発、クラウド基盤構築・運用、データ基盤構築を紹介するシングルページのコーポレートサイト
- サービス紹介、導入実績、会社概要のセクションで構成
- ライト/ダークテーマに対応

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | サイト本体(HTML / CSS を1ファイルに集約) |
| `.gitignore` | Git管理から除外するファイルの設定 |

## ローカルでの確認方法

`index.html` をブラウザで直接開くか、簡易サーバーを起動して確認できます。

```bash
python3 -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` にアクセスしてください。
